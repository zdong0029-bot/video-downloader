# 网盘原文件适配

## 来源

- LinkSwift：<https://github.com/hmjz100/LinkSwift>，本次核对用户提供的 main 分支 v1.1.3 脚本。
- OpenList 的现行 123 分享与移动云盘分享协议：<https://github.com/OpenListTeam/OpenList>。
- 天翼、迅雷分享的文件列表参数通过各自官方网页的正常请求核对。

新增适配器根据这些官方请求协议编写。没有运行远端用户脚本、第三方解析服务或脚本中的镜像替换功能。参考项目的 AGPL-3.0 许可证保存在 licenses 中；新增 LinkSwift 适配模块按 AGPL-3.0 提供源码。

## 八个网盘

| 网盘 | 原文件下载途径 | 分享处理 |
|---|---|---|
| 百度 | 已接入的 BaiduPCS-Go 官方账号通道 | 保留已有直下、任务转存及完整下载后清理流程 |
| 阿里 | LinkSwift Windows 6.0 原文件接口，带账号令牌续期 | 直下优先；平台要求转存时只处理本任务目录 |
| 夸克 | 普通原文件接口；网页大小限制时使用 LinkSwift 3.20 原文件接口 | 直下优先；必要转存经完整性校验后清理 |
| UC | LinkSwift UCBrowser 原文件接口与严格字节范围请求 | 分享 token 和文件 token 绑定，直下优先；需要转存时只保存本次文件，完整校验后清理 |
| 123 | 现行官网 /b/api 分享接口 | LinkSwift 的旧 /api 路径已不能使用；权限与额度仍由官网决定 |
| 天翼 | LinkSwift Accesstoken 原文件接口 | 官网分享列表、访问码与子目录识别；原文件接口不返回地址则停止 |
| 移动 | 官网加密分享原文件接口 | 补齐 LinkSwift 未定义的分享分支；需要后台账号授权 |
| 迅雷 | LinkSwift 自有文件接口、官网分享文件接口 | 隐藏官网客户端更新正常会话；分享不给原文件时按官网流程转存至本任务目录，完整校验后清理 |

账号连接通过原首页管理员区域操作，授权采用 Windows DPAPI 加密保存。连接成功仅代表官网账号检查通过，不表示任意分享或大文件测试通过。分享过期、平台额度、人工验证和下载权限会影响实际结果。

## 原文件与速度

- 不使用 presentURL、play_url、medias 或转码预览地址代替原文件。
- 下载必须满足官方文件大小；有可信来源 MD5/SHA1 时校验哈希。迅雷使用官方 GCID 对整份文件校验；只有 GCID 验证通过时，才不会把其 CDN 不对应原文件的 Content-MD5 当作来源哈希。
- 分段必须匹配精确 Content-Range 和同一对象版本，最终按顺序合并。
- HTTPS 连接发送标准 Host 主机名，避免额外 :443 使签名 CDN 返回 403。
- 同一次下载的暂时错误重试保留已验证分块，避免重新从零开始；对象版本变化、取消或最终失败时清理本次残片。
- 阿里最多 16 个分段连接，其他网盘最多 4 个；429/503 等暂时错误会退避重试，持续限流时自动降低并发并继续本次已验证分块。
- 迅雷公開分享请求与自有文件操作分开绑定：分享页暂未附加登录授权时，自有操作仍使用管理员已保存的同一账号；正常官网更新的 Cookie 不会被旧请求覆盖。
- 403 失效地址可续取，账号授权失效保留真实原因，不伪报下载完成。
- 迅雷临时目录清理由隐藏的官方网页客户端获取正常的操作会话；先复核本地全部成品与任务凭据，再核对云端目录 ID、名称、类型及所在目录，最后确认云端目录已删除。
- 下载速度由账号权限、服务商限速及当前网络共同决定；得到直链不等于解除限速。

只有实际测试通过的网盘和文件才能写为通过。缺少后台账号的测试必须记录“待授权”，不能用模拟测试代替真实下载。私有文件的测速与校验记录保留在本机，不随代码提交到公开仓库。
