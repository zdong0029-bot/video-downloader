# 下载工作台：浅色连续列表

本版保留白底、浅灰、蓝色按钮，小缩略图与紧凑列表。视频/图片、网盘/文件及下载记录在同一首页。

## 使用规则
- 本轮页面内新链接追加到现有工作区，多个主页分别建组；同时解析两个，其余排队。
- 素材列表随滚动继续加载，没有页码。全选展开，收起保留勾选。
- 工作区仅在内存记录本轮任务ID。刷新或重开网页后不显示上轮列表；历史任务可在下载记录查看。
- 当前页持续刷新后台准备进度和网页接收进度。刷新不取消主机任务；由网页流式接收的文件在刷新时会中断接收，需在下载记录重新保存。已交给浏览器原生下载管理器的大文件请在浏览器下载列表查看。
- 进行中的记录保留；结束后的成功、失败和取消记录保留七天，按任务结束时间计算。
- 到期清理记录不删除下载文件。服务器文件只能显式删除；网盘临时转存依旧按主机完整文件校验后清理。
- 链接输入草稿继续分视频/网盘保留；刷新恢复草稿不会自动重新提交。
- 普通访客按浏览器身份隔离，管理员可查看所有任务记录及后台账号。
- 画质选择、原文件下载和校验引擎保持原逻辑，不用列表缩略图代替成品。

## 文件
- static/workspace.css：浅色桌面及手机布局。
- static/index.html：工作区ID、记录页、筛选及紧凑成品列表。
- static/catalog-ui.js：来源组、素材选择、列表加载及关联下载进度。
- task_history.py：私有SQLite记录，不保存账号Cookie或密钥。
- app.py：记录持久化、结束时间及多主页队列。
- tests/test_task_history.py：期限、重启持久化、文件保留等回归。

## 验证
- 13项浏览器检查：多主页、追加、展开/收起、滚动、真实字节保存、刷新、记录、访客隔离、草稿、手机宽度及无JS错误。
- 6项历史记录回归。
- 14项现有主页解析回归。
浏览器用隔离测试服务与合成文件验证界面和状态流程，不将它作为各平台实网下载能力或速度报告。
