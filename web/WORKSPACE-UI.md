# 下载工作台：浅色连续列表

本版保留白底、浅灰、蓝色按钮，小缩略图与紧凑列表。视频/图片、网盘/文件及下载记录在同一首页。

## 使用规则
- 本轮页面内新链接追加到现有工作区，多个主页分别建组；同时解析两个，其余排队。
- 素材列表随滚动继续加载，没有页码。全选展开，收起保留勾选。
- 工作区仅在内存记录本轮任务ID。刷新或重开网页后不显示上轮列表；历史任务可在下载记录查看。
- 当前页持续刷新后台准备进度和网页接收进度。刷新不取消主机任务；由网页流式接收的文件在刷新时会中断接收，需在下载记录重新保存。已交给浏览器原生下载管理器的大文件请在浏览器下载列表查看。
- 进行中的记录保留；结束后的成功、失败和取消记录保留七天，按任务结束时间计算。
- 到期清理记录不删除下载文件。服务器文件只能显式删除；网盘临时转存依旧按主机完整文件校验后清理。
- 链接输入草稿继续分视频/网盘保留；刷新恢复草稿不会自动重新提交。
- 普通访客按浏览器身份隔离，管理员可查看所有任务记录及后台账号。
- 画质选择、原文件下载和校验引擎保持原逻辑，不用列表缩略图代替成品。

## 文件
- static/workspace.css：浅色桌面及手机布局。
- static/index.html：工作区ID、记录页、筛选及紧凑成品列表。
- static/catalog-ui.js：来源组、素材选择、列表加载及关联下载进度。
- task_history.py：私有SQLite记录，不保存账号Cookie或密钥。
- app.py：记录持久化、结束时间及多主页队列。
- tests/test_task_history.py：期限、重启持久化、文件保留等回归。

## 验证
- 13项浏览器检查：多主页、追加、展开/收起、滚动、真实字节保存、刷新、记录、访客隔离、草稿、手机宽度及无JS错误。
- 6项历史记录回归。
- 14项现有主页解析回归。
浏览器用隔离测试服务与合成文件验证界面和状态流程，不将它作为各平台实网下载能力或速度报告。

## 左侧导航与角色工作区（2026-10-13）

- 访客：左侧仅显示视频/图片、网盘/文件、下载记录；右侧为链接提交、来源组和小缩略图连续列表。
- 管理员登录后进入管理概览：左侧管理导航，右侧网盘账号与平台授权双列、近期任务及临时转存记录。
- 管理导航包含网盘账号、平台授权、全部任务、服务检查和管理员账号；点击“返回下载页面”可回到下载工作区。
- 返回下载页面恢复本浏览器范围；全部任务按管理员权限显示所有浏览器的记录。
- 工作区与后台使用同一套既有账号和下载API，未改动下载引擎和画质策略。服务端仍校验管理员权限。
- static/workspace-shell.js 负责角色布局及原控件的移动，保留原DOM标识及动作接口。
- 隔离服务通过13项下载界面回归；管理员导航、角色切换、手机宽度及访客管理API拒绝访问另行验证。

## 手机图片 / 视频保存到相册（2026-10-13）

- 手机成品行提供“保存到相册”，任务与主页分组提供“选中存相册”；适用于视频、图片与网盘中的媒体原文件。
- 原文件接收并核对长度后，用户再次点击按钮调用系统分享菜单。网站无法指定分享目标或确认相册已写入；不会自动宣称保存成功。
- 图片保留原图，视频保留原流；不为兼容相册进行压缩、截屏或转码。
- 批量最多每次16个，原文件准备内存预算128MB；大文件使用原文件下载，再从手机文件应用存相册。浏览器不支持系统文件分享或原始格式时提供下载备用入口。
- 取消系统菜单可重试。关闭预览会取消准备；快速重开不会误取消新的保存任务。不完整文件拒绝交给系统。
- static/media-save.js：原文件准备、图片/视频预览、批量分组和系统保存。
- tests/test_mobile_album_browser.py：模拟手机UA和系统分享API，验证原文件SHA256、MIME、点击激活、批次、失败与备用流程。用web/.venv运行，需要网站已启动；不等于手机真机相册验收。
