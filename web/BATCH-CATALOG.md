# 批量分组与主页视频选择（2026-10-11）

- 同一次提交的单视频链接合并显示；多视频分享和主页勾选下载保留独立卡片。
- 勾选、保存进度、移出列表仍绑定真实任务和文件，重名文件不会混淆。
- 多视频列表默认收起；全选自动展开，收起不取消勾选。长列表分段显示，选择范围包括所有已识别视频。
- 主页解析不下载媒体，识别到链接后可勾选下载；同一浏览器隔离预览列表和下载记录。
- 默认持续分页读取，没有固定 100/200 条上限。YouTube 会读取普通视频、Shorts、公开直播回放。
- 抖音通过官方页面的作品接口及可见视频链接读取；复用 cookies.txt 中未过期的抖音授权。
- 解析自动复用 cookies.txt / 可用 Firefox 授权并重试。平台未返回列表结束时，会标记结果不完整，不能当作“全部作品”。
- 登录、验证码、私密作品及平台接口限制可能阻止完整读取，不能承诺无需本人授权即可访问。
- 通用下载优先分辨率、帧率、码率；抖音先比较分辨率，再比较帧率、码率。不新增转码、压缩或放大。
- Symphony 保留 previewLink 原始源；实测样本 720×1280 / 24fps，码率高于平台同分辨率转码流。
- 新下载记录保存 batch_id，服务重启后保持合并显示。预览列表为临时缓存，重启后可重新识别。

## 验证

在 web 目录运行：

    .venv\Scripts\python.exe tests\verify_batch_catalog.py

测试在临时副本启动 127.0.0.1:18004，用固定测试视频检查：
10 个单视频 + 1 个多视频分享分成两个卡片、两组并行保存、文件 SHA256 一致、
245 条主页链接全选及只下载勾选项、浏览器隔离、移出列表保留文件、折叠/刷新、
文件定位按钮、手机布局、重启批次元数据。

测试需要 Playwright Chromium 和 ffmpeg；不会读取生产账号数据或改动生产下载记录。
