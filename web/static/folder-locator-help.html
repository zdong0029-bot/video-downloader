在当前电脑定位已保存的视频

安装一次扩展后，公网网页的“📁 定位”可打开当前电脑的文件夹，并选中已下载的视频。仅支持 Chrome / Edge 电脑版。

  1. 下载定位扩展压缩包，解压到长期保留的文件夹。
  2. Chrome 地址栏输入 chrome://extensions（Edge 输入 edge://extensions）。
  3. 打开“开发者模式”→“加载已解压的扩展程序”，选择含 manifest.json 的 Folder-Locator 文件夹。
  4. 等待正在进行的下载结束，再刷新下载器网页，点击视频右侧“📁 定位”。

请先点击“保存”并等浏览器下载完成。网页任务显示“完成”只表示主机已下载，当前电脑未必已有文件。若下载记录被清除，或文件被移动、改名，可能无法定位。可按 Ctrl＋J 手动查找。

扩展只在此下载器网站响应点击，不上传文件、下载记录或本机路径；不会删除文件。每台电脑、每个使用的浏览器需单独安装。
