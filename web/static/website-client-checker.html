网站连接检查器

适用于访问本下载器的 Windows 10/11 电脑。无需安装 Python、Tailscale 或浏览器扩展。

下载检查器 ZIP。建议提前保存，也可将压缩包发给亲友，网站打不开时仍能使用。

  1. 先解压全部文件，双击“检查网站.cmd”。
  2. 需要修复时输入 1，或双击“一键修复.cmd”，允许 Windows 管理员提示。
  3. 工具会重新检测各入口，只给本网站设置可用地址和代理例外，然后复测。
  4. 需要撤销时，双击“还原设置.cmd”。

工具不会关闭防火墙或整个代理，不删除视频及下载记录。若所有入口均不可达，或已有其他工具设置的地址映射，将停止并说明情况。它不能修复主机断电、服务商全面故障等问题，也不能保证换网后永久有效；再次异常可重新检测。

每台电脑分别运行。手机、macOS 和 Linux 不适用。检查结果保存在本机 %LOCALAPPDATA%\VideoDownloader-ClientChecker\last-check.json。
