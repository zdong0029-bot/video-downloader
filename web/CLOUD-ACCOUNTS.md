# 网盘分享下载与账号管理

打开原首页 http://127.0.0.1:8000/，管理员点击「网盘账号」。无需另外使用管理页面。

- 百度、阿里、夸克账号在官方网盘扫码，点击授权窗口的保存按钮。首次保存自动启用；已存在账号时可以手动切换。旧账号保留，凭据使用 Windows DPAPI 加密。
- 朋友只需粘贴分享链接及提取码。列表按浏览器隔离，管理员可查看全部。平台分享过期、容量、下载权限或登录失效仍可能导致下载失败，界面会显示实际错误。
- 下载原文件，不使用转码预览代替视频或安装包。获取到标准原文件哈希时进行校验；夸克 API 的非原文件 MD5 不用于误判，CDN 的 Content-MD5 会校验。所有文件必须按分享列表大小完整写入后才标记完成。

## 直下载和临时转存的统一规则

1. 优先用已连接账号取得原文件直链。平台允许取得原文件直链的分享无需转存，包含夸克自己账号的分享。阿里旧分享下载接口返回410时改用临时转存，不将接口失效误报成登录失败。
2. 平台要求转存时，百度使用 `/网站下载任务/<本次任务编号>`，夸克和阿里使用根目录 `网站下载任务-<本次任务编号>`。只注册由本次任务成功创建的目录。
3. 全部文件在**下载器主机**完成大小及可用的来源哈希校验，保存本地 SHA256 清理凭据，之后删除这个临时云端目录。浏览器的「保存」是在此后从主机取得文件；不会等待访客的浏览器下载完成才释放云端转存。
4. 原有网盘文件、原分享、其他任务目录不参与清理。直下载的源文件不会删除。平台的普通删除可能进入回收站，按各平台回收站和容量规则处理，不清空用户回收站。
5. 下载中断、取消或部分失败时，保留临时转存，禁止清理。管理员在原首页网盘账号区域可看到记录。
6. 文件已完整下载而清理失败时，任务仍可「保存」「定位」「移出列表」。管理员点击「重试清理」前会再次核验主机文件大小和 SHA256；即使切换了网盘账号，也使用原转存账号清理。凭据失效或本地文件缺失时拒绝删除。

## 本机私有数据

- `web/data/cloud-accounts/`：加密登录授权、账号选择与验证状态。
- `web/data/cloud-transfers/`：转存目录的任务归属、完整文件清理凭据和重试状态；管理接口只显示任务与状态。
- `web/private-baidu/`：百度下载组件运行配置，临时任务配置在退出时清除。
- 上述目录和下载产物不提交仓库。Windows 用户或电脑变化需要重新扫码。

## 验证方式

`python web/tests/test_cloud_downloads.py`：使用临时目录及模拟平台接口，验证原文件大小/来源哈希、CDN Content-MD5、断线续传、完整下载后的清理顺序、部分失败禁止删除、清理重试、账号切换及授权隔离。测试不会读取或修改实际网盘账号。

`python web/tests/verify_batch_catalog.py`：临时服务器和浏览器测试，验证多个批量任务、折叠/全选、列表隔离、移出保留文件、定位、移动页面及重启恢复。

实际平台链接测试应选可下载的有效分享；账号验证通过不等于所有分享都下载验证通过。阿里快传有效期独立于登录状态，过期快传必须更换链接。
