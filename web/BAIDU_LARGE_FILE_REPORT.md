更新：2026-10-12 10:26:53

## 实测结果

- 用户提供的分享原文件：362,218,646字节（345.44MiB）。没有转存。
- 三次完整文件下载通过；首轮20秒一次检查，完成观测上界60.047秒。两次访客精确计时29.093秒、30.078秒，平均11.874、11.485MiB/s，包含解析、合并、校验。
- 两次访客从网站文件接口完整接收362,218,646字节，SHA256与主机文件一致。另一访客访问记录均404。
- 百度列表MD5是混淆字符串，不能当作原件哈希。CDN的十六进制Content-MD5是真实整文件校验值，本地核对通过。

## 改动

1. 新账号正常授权原文件地址支持4MiB范围请求。整文件GET失败，旧的四等分下载对大文件也会超过服务端单段上限。百度专用通道改为最多4MiB的小段，3个并行连接。
2. 检查每段HTTP206、精确Content-Range、总长度和ETag；仅网络中断续传该段已写入偏移。权限失败、版本变化和数据损坏停止，不能假装完成。
3. 合并之后核对大小与真实Content-MD5。视频、图片、安装包均不转码、不重压缩。
4. 网页显示实际接收字节、速度及剩余时间，不把分段临时文件误算为0进度。
5. 主机文件准备完成后，256MiB以上文件直接交浏览器下载管理器写入磁盘，避免网页先缓存几GB Blob。交给浏览器时明确显示其下载列表负责进度与最终完成，不显示虚假100%。
6. 30项协议、范围、续传、凭据和清理检查通过；11项浏览器流程检查通过，包含大文件原生下载、未走Blob、未虚报完成及原有批量/移除/定位流程。

## 范围

这次速度是百度到主机的实际完整文件平均速度。公网首页HTTP200；本次没有将百度测试原件通过公网Funnel做完整测速，因此不能据此承诺朋友远程下载也是11.5MiB/s。公网还受主机上传带宽、Funnel和访客网络影响。

当前单网盘任务限制10GiB，分段合并需要约两倍原件空间。实际完整验收文件为345.44MiB，没有把2GiB或10GiB写成已经实测。旧账号接口编码结果和PCS慢速测试仍保留在累计报告；账号权限及平台策略变化也可能影响后续下载。

## 资料核实

- [BaiduPCS-Py原作者下载说明](https://github.com/PeterDing/BaiduPCS-Py#下载文件或目录)：大于5MB文件需要小块请求，单块超过5MB会失败。结合本账号真实206响应，独立实现4MiB原文件通道。
- [百度bdpan-storage](https://github.com/baidu-netdisk/bdpan-storage)：支持分享转存下载，但当前不支持原生Windows，并且需要单独OAuth；此次没有引入这套依赖。

报告未保存账号凭据、私人分享链接、文件名或签名下载地址。旧失败与完整成功均可在[累计报告](PLATFORM_TEST_REPORT.md)查看。
