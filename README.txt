视频下载器（统一版）
====================

双击 Downloader.cmd，粘贴链接，回车。自动识别来源：

  Symphony 分享链接 / UUID  ->  Symphony_Videos
  TikTok / YouTube 等链接   ->  Web_Videos

命令
----
  O   打开目录（可选 Symphony_Videos / Web_Videos / Logs）
  L   切换预览模式（只解析不下载，看看里面有什么）
  Q   退出

特性
----
- 下载完成后自动打开视频所在文件夹，直接就能看到文件
  如果那个文件夹已经开着，会把已有窗口拉到最前面，不会堆一堆重复窗口
  窗口被最小化了也会自动还原
- 下载过程实时显示进度，不再等到最后才一次性输出
- 视频文件夹里只有视频，没有杂项文件
  已下载记录存在脚本目录的隐藏文件 .web-archive.txt 里，不占用视频文件夹
- 重复运行自动跳过已下载的内容
- 每次运行的日志保存在 Logs 文件夹，失败时自动打开
- Symphony：只取每个素材的最高画质原片；同名素材用 vid 后缀区分，不会互相覆盖
- TikTok：取的是无水印源，不是网页下载按钮那个带水印的版本
- YouTube：文件本身无水印，播放器右下角的频道图标是叠加层，下下来自然没有
            如果水印是创作者烧进画面的，本工具去不掉

画质说明（重要）
----------------
下载的是**可用的最高画质**，不会模糊。

YouTube 把高清视频和音频分成两条独立的流存放，1080p 以上只有纯视频流没有声音。
必须用 ffmpeg 把两条流合并，才能得到又清晰又有声音的文件。
没有 ffmpeg 的下载工具只能选"已经合好"的格式，那种通常最高 720p——
这就是很多人用别的工具下出来觉得糊的真正原因，不是工具"压缩"了视频。

本工具默认参数 bv*+ba，意思是"最好的视频流 + 最好的音频流，然后合并"，
所以源视频是 4K 就下 4K，是 1080p 就下 1080p。

另外还指定了画质排序 -S res,fps,tbr（分辨率 -> 帧率 -> 码率）。
这一条很关键：yt-dlp 默认把"编码格式新"排在码率前面，
在 TikTok 上会选中同样 720p 但码率只有三分之一的 H.265 流，
分辨率没缩水，细节却被压没了，看起来明显发糊。
改成按码率排序后，同分辨率下永远取码率最高的那个版本。

实测同一条 TikTok 视频：
  修复前  h265  371 kbps   300 KB   发糊
  修复后  h264  855 kbps   691 KB   清晰

这个规则对所有视频通用，不是针对某一条调的。实测 4 条不同的 TikTok 视频
（含横屏），最高分辨率那一档里永远同时存在 h264 高码率和 h265 低码率两个版本，
先按分辨率再按码率排，每次都落在 h264 高码率那个上。

想确认某条视频选的对不对，可以自己查：
  powershell -File Get-WebVideos.ps1 -Url "链接" -ShowFormats
会列出所有可用画质档，并标出本工具会选中哪一个。

副作用：YouTube 4K 会选中码率最高的流，文件可能很大（十分钟的片子能到 2 GB）。
嫌大就限制高度：
  powershell -File Get-WebVideos.ps1 -Url "链接" -MaxHeight 1080

TikTok 源视频本身一般就是 1080x1920 或更低，下下来和原片一致。

大文件会不会下不动
------------------
不会。针对大文件做了这些处理：

- 断点续传：中断后重跑同一个链接会接着下，不用从头开始（yt-dlp 默认行为）
- 无限重试：网络抖动、连接被重置都会自动重试，间隔逐次拉长
- 连接超时 30 秒：卡死的连接会被掐掉重连，不会无限期挂在那里
- 分片并发 4 路：大文件下载更快也更抗断
- 未完成的 .part 临时文件会保留，就是为了续传

重要：下到一半失败不会被谎报成功。
统计以 yt-dlp 退出码为准，残留的 .part 文件不算成品——
否则一个下到一半的 2GB 文件会被报成"下载完成"，你打开才发现是坏的。
失败时会明确告诉你有几个未完成文件，重跑即可续传。

磁盘空间要自己留意：4K 长视频可能几个 GB，空间不够 yt-dlp 会报错并保留已下部分。

首次下载 TikTok / YouTube
-------------------------
需要 yt-dlp（ffmpeg 会作为依赖自动一起装）。
启动器检测到缺失时会询问是否自动安装，按 Y 即可。
装完如果仍提示找不到，关掉窗口重开一次。

也可以手动装：
  winget install yt-dlp.yt-dlp

文件说明
--------
  Downloader.cmd             入口，双击这个
  Start-Downloader.ps1       统一启动界面
  Get-SymphonyVideos.ps1     Symphony 下载引擎
  Get-WebVideos.ps1          TikTok / YouTube 下载引擎（yt-dlp 封装）
  Symphony-Downloader.cmd    旧入口，已转发到新界面，可删
  Start-SymphonyDownloader.ps1  旧启动界面，已被取代，可删

四个程序文件请放在同一目录，不要单独移动。

注意
----
Symphony 分享链接 30 天过期且无法停用，任何拿到 URL 的人都能访问那批素材。
下载自己的内容没问题；下载他人作品并去除水印后二次发布涉及版权与平台条款，风险自担。
