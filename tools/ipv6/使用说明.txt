Windows 10 / 11 IPv6 一键启用工具

1. 解压整个文件夹，不要只复制某一个文件。
2. 双击 Enable-IPv6.cmd，Windows 弹出管理员授权时点击“是”。
3. 程序自动启用物理网卡的 IPv6，保留 IPv4，并显示检测结果。
4. Check-IPv6.cmd 只检查，不修改设置。
5. Restore-Settings.cmd 可还原本机第一次使用本工具之前记录的 IPv6 设置。

本工具不需要安装 Python 或其他软件。不要直接在 ZIP 压缩包中运行。
不会修改 Wi-Fi 密码、DNS、网关、防火墙，也不会自动重启电脑。
首次修改的备份保存在 C:\ProgramData\VideoDownloader-IPv6Helper。
开启网卡协议时，Windows 可能短暂重新配置网络。

重要：启用 IPv6 不等于运营商提供了 IPv6。
若只有 fe80 开头的地址，不能据此认定能通过 IPv6 访问互联网。
如果提示没有公网 IPv6，需要路由器和运营商支持，软件无法代替它们。
如果提示需要重启，请自行保存工作后重启，再运行 Check-IPv6.cmd。
外网测试仅尝试连接 api6.ipify.org 的 IPv6 443 端口，不上传文件、密码或账号。

访问 IPv6 下载器还需要：服务端公网入口、域名、HTTPS 以及路由器入站放行均配置正常。
本工具不会让一个仅有 IPv4 的网络自动具备 IPv6 互联网服务。
